# aiprohar.ru

Это единственный репозиторий публичного сайта <https://aiprohar.ru>.

## Публикация

- Источник GitHub Pages: ветка `main`, корень репозитория.
- Custom domain: `aiprohar.ru`.
- DNS обслуживается Beget.
- Перед публикацией запустите `powershell -ExecutionPolicy Bypass -File .\tools\check-local-links.ps1`.

## Границы репозитория

Здесь хранятся только статические публичные страницы и их ресурсы. Секреты, `.env`, серверный код, боты, журналы инструментов и внутренние документы добавлять нельзя.

Боты, приложения и остальные рабочие проекты находятся в [`my-first-project`](https://github.com/prohar2f-pixel/my-first-project). Сайт `aiprohar.ru` там не поддерживается.
