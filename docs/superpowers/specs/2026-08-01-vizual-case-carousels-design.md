# Дизайн двух каруселей для кейса «Визуал»

## Цель

Заменить длинную галерею экранов двумя быстрыми для просмотра каруселями: сначала десктопная версия проекта, затем мобильная. Пользователь должен оценить структуру сайта за несколько переключений без длинной прокрутки.

## Структура

### Десктопная карусель

- Широкий презентационный кадр 16:10.
- Слайды: главная, каталог, карточка объекта, команда и контакты.
- Под каждым кадром: короткий заголовок, одно предложение о назначении экрана и счётчик.
- Стрелки, точки навигации и клавиши Left/Right.

### Мобильная карусель

- Отдельный блок после десктопной карусели.
- Вертикальный экран в спокойной рамке телефона.
- Слайды: мобильная главная, каталог, карточка объекта и команда.
- Свайп, стрелки, точки и текстовое описание.

## Визуальная система

- Существующая тёмная палитра кейса сохраняется.
- Акцентный фиолетовый используется только для активной точки, фокуса и кнопок управления.
- Скриншот остаётся главным элементом; текст занимает вторичную компактную область.
- Высота каждого типа карусели стабильна, чтобы страница не прыгала между слайдами.
- Подписи ограничены двумя строками и не дублируют очевидное содержимое изображения.

## Поведение и доступность

- Автопрокрутка отсутствует.
- Каждая карусель имеет собственное состояние и собственные элементы управления.
- Кнопки получают понятные `aria-label`, текущий слайд сообщается через `aria-live`.
- Неактивные слайды исключаются из фокуса и скрываются от вспомогательных технологий.
- Учитывается `prefers-reduced-motion`.
- При отключённом JavaScript первый слайд и его описание остаются видимыми.

## Изображения

- Используются только реальные экраны работающего сайта.
- Десктопные кадры оптимизируются в WebP и показываются в едином отношении сторон.
- Для мобильной карусели подготавливаются отдельные реальные скриншоты, а не обрезки десктопных страниц.
- Размеры и `loading="lazy"` задаются явно, чтобы избежать скачков макета.

## Проверка

- Разрешения: 390, 768, 1024 и 1440 px.
- Клики по стрелкам и точкам, клавиатура, свайп.
- Отсутствие горизонтальной прокрутки и изменения высоты при переключении.
- Отсутствие ошибок консоли и повреждённых изображений.
- Статический первый слайд остаётся читаемым без выполнения JavaScript.
